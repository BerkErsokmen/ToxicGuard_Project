# 6. PROJECT SCHEDULE AND TASK SHARING

The project timeline for ToxicGuard is structured to ensure systematic development from initial data exploration to final deployment. The table below outlines the specific tasks, assigned personnel, timeline, and success criteria for each phase of the system development life cycle.

| WP No | Work Package Name | Assigned project staff | Time Period (..-.. Week) | Success Criteria |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Data Collection & Preparation** (EDA, Feature Engineering) | Project Team | Week 1-2 | Cleaned dataset, balanced classes, robust TF-IDF vectorization, and completion of EDA report. |
| **2** | **Baseline Model Training & Evaluation** (LR, XGBoost, RF) | Project Team | Week 3-5 | Successfully trained baseline models, hyperparameter tuning completed, and F1-score/ROC-AUC evaluation table finalized. |
| **3** | **Advanced Model Integration** (Transformers & LIME XAI) | Project Team | Week 6-9 | Fully functional multilingual Transformer model (XLM-RoBERTa/DistilBERT) integrated with functional LIME explainability. |
| **4** | **Web Application Development** (Streamlit UI) | Project Team | Week 10-12 | Real-time web interface deployed with features for single text analysis, batch CSV uploading, and side-by-side model comparison. |
| **5** | **Deployment & Documentation** (Docker & Reporting) | Project Team | Week 13-14 | Application fully containerized via Docker and submission of the comprehensive academic project report. |
