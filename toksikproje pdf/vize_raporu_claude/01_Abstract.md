# ABSTRACT

The rapid proliferation of digital communication platforms has led to a significant increase in online toxicity, encompassing hate speech, harassment, cyberbullying, and targeted abuse. This project presents **ToxicGuard**, an automated machine-learning-based toxicity detection system designed to accurately identify and classify harmful content within user-generated text. The system leverages the Kaggle Jigsaw Toxic Comment Classification Challenge dataset, employs a comprehensive NLP preprocessing pipeline, TF-IDF feature engineering, and evaluates multiple classification algorithms including Logistic Regression, Random Forest, and XGBoost. Class imbalance is addressed through SMOTE and dynamic class-weighting. Later iterations incorporate a fine-tuned DistilBERT Transformer model and LIME-based explainability. The finalized system is deployed via an interactive bilingual Streamlit web application supporting real-time analysis and batch CSV processing, providing platform moderators with a transparent and practical content moderation assistance tool.

**Keywords:** Toxicity Detection, Natural Language Processing, Machine Learning, Multi-Label Classification, TF-IDF, XGBoost, Transformer, DistilBERT, XLM-RoBERTa, LIME, Explainable AI, Content Moderation, Streamlit, Cyberbullying, Hate Speech Detection
