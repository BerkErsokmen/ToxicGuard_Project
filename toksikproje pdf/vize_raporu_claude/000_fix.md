## 5.8 Multilingual Transformer Model: XLM-RoBERTa

The V4 iteration extends ToxicGuard's capability to multilingual toxicity detection through a fine-tuned XLM-RoBERTa [18] model. XLM-RoBERTa is a cross-lingual variant of RoBERTa [8] pre-trained on 2.5 TB of CommonCrawl data spanning over 100 languages, enabling robust cross-lingual transfer learning. By fine-tuning on a combined English–Turkish toxicity corpus, the V4 model can classify toxic content in both languages within a single unified architecture, eliminating the need for separate per-language models. The model uses SentencePiece tokenization with a shared multilingual vocabulary of 250,000 subword units. Fine-tuning follows the same multi-label classification head design as V3 (linear layer with sigmoid activations), trained with the AdamW optimizer, binary cross-entropy loss with per-class weighting, and early stopping on validation Macro F1-Score. The multilingual architecture directly addresses the Perspective API's documented limitation of restricted language coverage, enabling ToxicGuard to serve linguistically diverse communities from a single deployment.
