# 1. ABSTRACT

The rapid proliferation of digital communication platforms has revolutionized the way individuals interact, share information, and participate in public discourse. However, this expansion has concurrently led to a significant increase in online toxicity, encompassing hate speech, harassment, cyberbullying, and profanity. Such malicious behaviors severely degrade the user experience, undermine psychological well-being, and discourage constructive online engagement. To mitigate these issues, automated toxicity detection systems have become an essential component of modern digital infrastructure. This project presents the development and evaluation of 'ToxicGuard', an automated, machine learning-based toxicity detection system designed to accurately identify and classify toxic content within user-generated text. Leveraging the widely recognized Kaggle Jigsaw Toxic Comment Classification Challenge dataset, the proposed system employs a comprehensive data preprocessing pipeline, advanced feature engineering techniques such as Term Frequency-Inverse Document Frequency (TF-IDF), and a comparative analysis of multiple classification algorithms including Logistic Regression, Random Forest, Custom Ensemble Models, and eXtreme Gradient Boosting (XGBoost). A critical focus of the project is addressing the severe class imbalance inherent in toxicity datasets, utilizing advanced strategies like SMOTE and dynamic class-weighting to significantly improve minority class recall rates. The final optimized models are successfully deployed via an interactive Streamlit graphical web application, enabling both rapid real-time text analysis and massive batch processing capabilities. Through rigorous operational performance evaluation, this engineering project aims to systematically provide a highly scalable, legally transparent, and functionally effective tool that empowers digital platform moderators to consistently maintain safe, exceptionally inclusive, and psychologically healthy online communities.
