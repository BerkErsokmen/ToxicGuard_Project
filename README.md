# Mezuniyet Projesi — ToxicGuard

Bu repo, 'ToxicGuard' projesinin kaynak kodunu ve analiz sonuçlarını içerir. Ana klasör yapısı ve önemli dosyalar:

- `app/` — Streamlit uygulaması
- `data/` — Temizlenmiş veri ve test parçaları
- `models/` — Eğitilmiş modeller
- `reports/` — Raporlar ve adım adım notlar
- `analiz_sonuçları/` — Model test sonuçları (yüklenecek klasör)
- `toksikproje pdfs/` — Yarışma kaynakları ve lider notları

Yükleme talimatları:
1. GitHub Desktop ile bu klasörü yerel depo olarak ekleyin.
2. Değişiklikleri gözden geçirip `Publish repository` ile GitHub'a gönderin.

Not: Büyük veri dosyalarını depoya eklememek için `.gitignore` kullanın.
